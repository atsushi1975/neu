# ノイ (Neu)

場の数字の合計が **101 を超えないように** カードを出し合うカードゲーム
「ノイ (Neu)」のオンライン対戦実装です。

フェーズ2まで完了しており、**Flask + 素の JavaScript** で
部屋作成 → 参加 → 開始 → 対戦 → 結果表示まで遊べます。
ルール判定は `neu/engine.py` に閉じており、UI / API 側では再実装していません。

## 必要なもの

- Python 3.10 以上
- Flask（`requirements.txt`）

## 起動

```bash
python3 -m pip install -r requirements.txt
python3 app.py --port 5001
```

ブラウザで `http://localhost:5001/` を開きます。スマホ縦画面を優先した UI です。

1. 名前を入れてルームを作成
2. 表示されたルーム ID を仲間に共有（または同じ画面のルーム一覧から参加）
3. 2〜7 人がそろったら、ホストが「ゲームを開始」
4. 手番になったら、手札のカードをタップするとその場で出る（即出し）
5. SHOT は、手札の SHOT をタップしてから、卓上の指名できる席をタップして出す
6. 出せるカードがすべて 101 を超えるとラウンド負け。チップが尽きると脱落し、最後の1人が勝者

ルールの要点:

- 合計が **101 を超える数字カードは出せない**。
- 手番の人が「次に出すカードがどれを出っても 101 を超える」状態なら、カードを出す前に
  その人のラウンド負け。チップが尽きると脱落し、最後の1人が勝者。
- 出したカードは場札の山（`table`）の一番上に積む。ゲーム開始時は全カードをシャッフルして
  3枚ずつ配るだけ（場札は空・合計0から始める）。ラウンドが終わってもカードを回収・
  配り直さず、場札は積み上がったままで合計だけ0に戻る。山札が尽きたときだけ場札をシャッフルする。

## 主な機能

- 部屋作成・参加・退出・ホスト引き継ぎ
- SSE によるリアルタイム更新
- 自分の手札だけを公開（他人の手札は枚数も中身も表示しない）
- 手番の人はカードをタップで即出す（2タップ確認・「出す」ボタン・アクションパネルは廃止）
- 出せるカードには「出すと合計 XX」（`afterSum`）バッジ、101 超え（`busts`）は赤い「超過」バッジを表示
- SHOT は円形卓の「指名できる席」だけが光って、タップで指名して出す
- 手番通知（プロンプト・ページタイトル・対応端末では振動）
- 場の合計は卓の中央に1か所、場札は一番上の1枚だけ、山札は裏面1枚＋残り枚数を表示
- 回る向きは「↻ 時計回り」「↺ 反時計回り」の文字1か所だけ（矢印の図形・回転アニメーションはなし）
- ラウンド敗者はサーバーの `lastRound.message` とチップ残り・脱落・次の最初の手番をトースト表示（手札は出さない）
- ゲーム終了時は勝者発表を優先
- カード画像が無い場合の CSS 仮カード表示

## 退出システム（承認制）

進行中のゲームを途中で抜けるには、他の全員の許可が必要です。
ヘッダの「退出」ボタンから申請すると、他のプレイヤーに「許可 / 拒否」の帯が表示されます。
全員が許可するとゲームは中止され、全員がロビーに戻ります。
拒否または 30 秒の時間切れで却下され、申請者は 120 秒再申請できません（取り消しはクールダウンなし）。
ゲーム終了後は承認なしで即退出できます。

## テスト

```bash
python3 -m unittest discover
node static/table-layout.test.js
```

現在 130 テスト（エンジン・アダプタ・API 結合）が通ります。
`tests/ui_check.py` は実ブラウザ（Playwright / Chromium）で対戦画面を確認する手動実行用スクリプトです（unittest の対象外）。

```bash
python -m playwright install chromium   # 初回のみ
python tests/ui_check.py                # ポート5001でアプリを自動起動して確認
```

## 手動確認の手順（テストプレイ後 UI 改善）

- 2〜7 人それぞれで円形卓が崩れないこと（席が重ならない・卓の枠からはみ出さない）
- TURN で「↻ 時計回り」「↺ 反時計回り」の文字が切り替わること
- SHOT の指名（SHOT をタップした直後の席タップでも成功すること）
- 即出し
- DOUBLE 中のグレーアウト
- 出せないカードのグレーアウトと「超過」バッジ
- 場札が一番上の1枚だけ表示されること（重なり・傾きなし）
- 場の合計が卓の中央1か所だけに表示され、プレイ後に更新されること
- ラウンド結果トーストに手札が出ないこと
- スマホ幅（390×844 / 360×640）でスクロールなしで収まること

円形卓の座標計算は `static/table-layout.js` の純粋関数として node でテスト済み（`node static/table-layout.test.js`）。
